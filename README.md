# Inglés en juego

Página para estudiar inglés, del A1 al C2, con juegos, misiones y un examen final.

Juega aquí: https://walter3107.github.io/ingles-en-juego/

El progreso se guarda en el navegador de cada dispositivo. Para pasarlo de un aparato a otro, usa los botones de exportar e importar en la página.
